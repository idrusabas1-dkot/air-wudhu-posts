# air-wudhu-posts
Gambar posting harian halaman Facebook Air-Wudhu.
- `queue.json`: antrean 21 konten (fiqih ibadah). `posted.json`: id yang sudah terbit.
- `scripts/make_post.py out.png "Judul" "Isi" "Sumber"`: membuat gambar 1080x1080.
- `images/`: gambar publik yang dipakai Facebook lewat URL raw.githubusercontent.com.
